# Tiempo critico en Bolivia 

## Descripción del Proyecto

Este proyecto fue desarrollado para la materia **Programación Web I**.

La aplicación web permite simular situaciones relacionadas con el abastecimiento de recursos, el aumento de precios y la administración del presupuesto familiar en contextos de crisis económica.

El objetivo es mostrar mediante cálculos interactivos cómo estos factores pueden afectar a las familias y ayudar a comprender mejor la toma de decisiones económicas.

## Funcionalidades

### 1. Simulador de Abastecimiento de Carburantes

Permite calcular cuántos días durará una reserva de combustible considerando:

* Reserva inicial.
* Consumo diario.
* Reabastecimiento diario.
* Nivel crítico de reserva.

#### Resultados

* Días hasta alcanzar el nivel crítico.
* Reserva final estimada.
* Mensajes de alerta.

---

### 2. Simulador de Precios de Alimentos

Permite analizar el impacto del aumento de precios en la economía familiar.

#### Datos solicitados

* Nombre del producto.
* Precio anterior.
* Precio actual.
* Cantidad consumida.

#### Resultados

* Gasto anterior.
* Gasto actual.
* Diferencia de gasto.
* Porcentaje de aumento.

---

### 3. Simulador de Compras Familiares

Permite verificar si un presupuesto es suficiente para realizar una compra.

#### Datos solicitados

* Presupuesto disponible.
* Precio del producto.
* Cantidad a comprar.

#### Resultados

* Costo total de la compra.
* Saldo restante.
* Monto faltante.
* Mensaje indicando si el presupuesto alcanza o no.

## Casos de Estudio

* Reserva inicial: 10000 litros

* Reabastecimiento diario: 300 litros

* Precio actual: 11 Bs

### Caso 3: Compras Familiares
